# 🚀 EmpTrack Pro – Enterprise Employee Management System

EmpTrack Pro is a Java Spring Boot backend application for managing employees and departments in an organization. It includes REST APIs for CRUD operations, search, sorting, and filtering, and supports advanced features like JWT-based security, CSV export, scheduled tasks, and Docker deployment.

---

## 📌 Features

✅ Manage Employees (CRUD)  
✅ Manage Departments  
✅ Search, Filter, Sort Employees  
✅ Global Exception Handling  
✅ DTOs and Model Mapping  
✅ REST API with Swagger Docs  
✅ Unit Testing with JUnit & Mockito  
✅ Scheduled Jobs  
✅ CSV Export of Data  
✅ Role-based Security (JWT) – optional  
✅ Docker Support – optional  
✅ Email Notifications – optional
